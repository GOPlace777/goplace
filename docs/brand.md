# GO PLACE 브랜드 가이드

(2026-11-13 확정 · 방향 B "기술 라임", 사용자 선택)

## 1. 브랜드 한 줄

> **GO PLACE — 운동하는 곳에서, 계속 앞으로.**
> 사람들이 운동하는 "곳(PLACE)"에서 시작해 꾸준히 "성장(GO)"하도록 돕는 스포츠테크 브랜드.

## 2. 로고

| 파일 | 쓰는 곳 |
|---|---|
| `brand/symbol.svg` / `.png` | 기본 심볼 (라임 핀 + 블랙 화살표). 프로필 사진, 작은 표시 |
| `brand/symbol-ink.svg` / `.png` | 밝은 바탕용 심볼 (블랙 핀 + 라임 화살표) |
| `brand/lockup-dark.svg` / `.png` | 가로 로고, 어두운 바탕 (기본) |
| `brand/lockup-light.svg` / `.png` | 가로 로고, 밝은 바탕 |
| `brand/app-icon-chaeryeok.png` | 체력특급 앱 아이콘 (GO PLACE 화살표 사용) |

**심볼의 뜻**
- **위치 핀** = PLACE: 체육관, 복싱장, 연병장처럼 사람들이 운동하는 곳
- **위로 향한 이중 화살표** = GO: 앞으로, 위로 성장. 아래 화살표를 흐리게 해서 "어제보다 오늘"을 표현

**지킬 것**
- 심볼 주변에 심볼 너비의 1/4 이상 여백을 둔다.
- 심볼을 늘리거나 기울이거나 다른 색으로 바꾸지 않는다.
- 군·정부 상징(계급장, 국방부 로고 등)과 함께 쓰지 않는다.

## 3. 색상

| 이름 | 코드 | 역할 |
|---|---|---|
| **볼트 라임** | `#C6FF3D` | 브랜드 대표색. 버튼·강조 배경, 어두운 바탕 위 글씨 |
| **GO 블랙** | `#111418` | 기본 바탕(다크), 라임 위 글씨, 로고 글자 |
| 올리브 (글씨용) | `#4D7C0F` | 흰 바탕 위 강조 글씨 (라임은 흰 바탕에서 읽기 어려움) |
| 연한 라임 | `#F5FBE6` / `#ECF7CC` | 밝은 화면의 카드·보조 버튼 배경 |
| 라임 테두리 | `#DDEFB0` | 연한 테두리 |
| 화이트 | `#FFFFFF` | 밝은 바탕 |

**색 사용 규칙 (중요)**
1. **라임 배경 위에는 항상 블랙 글씨.** (흰 글씨 금지)
2. **흰 바탕 위 글씨에는 라임을 쓰지 않는다.** 강조 글씨는 올리브 `#4D7C0F`.
3. 화면에서 라임은 **포인트**로만: 주요 버튼, 현재 상태, 핵심 숫자. 넓은 면적은 블랙 또는 화이트.
4. 앱 코드에서는 색을 직접 쓰지 않고 CSS 변수(`--brand`, `--on-brand`, `--brand-text` 등)로 관리한다.

## 4. 글자

- 로고 글자: 굵은 산세리프 대문자 `GO PLACE` (두 줄 쌓기 또는 한 줄)
- 앱 화면: 휴대폰 기본 글꼴 (한글 가독성 우선)

## 5. 브랜드 구조: GO PLACE = 모회사 (2026-11-13 확정)

**보증형(혼합형)**: 제품마다 고유 이름 + "by GO PLACE". 모든 제품이 같은 색상·심볼·디자인 언어를 쓴다.

```
GO PLACE (모회사)  — 원칙·브랜드·공통 디자인 = goplace 저장소
├── 체력특급 by GO PLACE   — 공익·무료·장병용, 데이터 수집 없음 (저장소 unit-fitness-app)
├── GO LIFT by GO PLACE    — 웨이트·파워리프팅 (개인용으로 시작, 별도 저장소)
└── (미래) GO GYM · GO FIGHT · GO RUN …  — 헬스장·복싱장·달리기 (조사 단계)
```

**이름 규칙**
- 민간 제품: **"GO + 운동/장소"** (GO LIFT, GO GYM, GO FIGHT, GO RUN …)
- 공익 제품(체력특급): 고유 한글 이름 유지 → 민간 제품과 분리

**지킬 것**
- 제품마다 저장소·데이터·서비스 정책을 따로 둔다. 제품 간 사용자 데이터를 섞지 않는다.
- 각 제품 화면·공유 이미지에 작게 **"by GO PLACE"**를 표시한다.
- Play Console 개발자 이름: **GO PLACE** (실명 대신 브랜드명)
- 지금의 "모회사"는 브랜드 개념이다. 실제 회사(사업자·법인)는 복무 규정 확인 후 또는 전역 후.
- 이름을 오래 쓰기 전에 KIPRIS(특허정보검색서비스)에서 "GO PLACE", "고플레이스", "GO LIFT" 상표를 확인한다.

## 6. 말투

- 짧고 힘 있게, 그러나 과장하지 않는다. ("특급까지 7개 더", "이번 주 루틴 완주!")
- 남과 비교하기보다 **어제의 나와 비교**하는 표현을 쓴다.
- 공식 기관처럼 보이는 표현을 쓰지 않는다.
