# 매월 고정 수입 모델 v0 — 유튜브 + 웹·앱 연결

(2026-11-25 · 대표와 Claude의 대화 · 상태: **11-27 대표가 A를 조사 1순위로 선택** (개발·판매 아님) · 질문 크기 XL → `docs/thinking-system.md` 6단계)
(관련: `docs/strategy.md` v0 "몸의 진실을 재는 회사" — 이 문서는 그 지도 위에서 "첫 돈을 어디서 버나"를 다룬다)

## 0. 대표의 출발점 (2026-11-25)

- 유튜브는 지금 쉬는 중. 예전에는 **복싱 선수 분석 영상**을 올리고, **유명 선수들의 훈련 영상을 판매**했다. [사실, 대표 말]
- 지금 생각: AI로 웹사이트·앱을 만들 수 있으니, 유튜브와 연결해 수익 모델을 만들고 싶다.
- 누구에게 무엇을 팔지는 아직 못 찾았다. 큰 틀은 **"군 적금을 활용해 매월 고정 수입을 먼저 만든다."**

## 1. 본질 (STEP 1)

| 겉 질문 | 진짜 문제 |
|---|---|
| 유튜브 + 앱으로 어떻게 돈을 버나? | **누가, 어떤 반복되는 문제 때문에, 매달 돈을 낼까?** |

- "매월 고정 수입"은 **대표의 필요**다. 고객은 대표의 필요 때문에 돈을 내지 않는다. 고객은 **자기 문제가 매달 다시 생길 때** 매달 낸다. → 반복되는 고객 문제를 먼저 찾는다.
- 숨은 제약 [사실]: 복무 중 **수익 금지**(부대 확인: "수익이 없으면 괜찮다"), 휴대폰만, 시간 부족. → 실제 수입은 법무관 확인 또는 전역 후. **지금은 준비 기간.**

## 2. 냉정하게 짚을 3가지 (STEP 2·5)

1. **군 적금은 개발비로 쓰지 않는다.** [판단, 확신도 높음]
   - AI 덕분에 만드는 비용은 거의 0이 됐다 [사실: 체력특급은 Play 등록비 외 개발비 0원].
   - 돈이 진짜 필요한 곳은 **고객을 찾는 일**(광고 시험, 인터뷰)인데, 그것도 수십만 원 단위로 시작할 수 있다.
   - 적금의 진짜 역할 = **전역 후 실패해도 다시 시도할 수 있는 시간(활주로)**. 사업이 첫 고객을 찾기 전에 적금이 다 녹으면 게임이 끝난다.
   - 정직하게: "매월 고정 수입"만이 목표라면, 가장 확실한 길은 사업이 아니라 직장·예금이다. 사업은 **불확실하지만 크게 자랄 수 있는 길**이고, 둘은 다른 선택이다. (투자 상품 추천은 하지 않는다)
2. **"AI로 웹·앱을 만들 수 있다"는 모두에게 사실이다.** → 해자가 아니다 (`CLAUDE.md` 4-3). 남는 것은 **대표만 가진 것**:
   - 복싱 선수 분석 안목, 복싱 팬에게 **실제로 판매해 본 경험** (지불 의사의 증거 — 맘 테스트 기준 가장 강한 신호)
   - 장병·입대 예정자 고객 이해 (릴스 3편: 18~24세 59% 적중)
   - 앱을 출시까지 끌고 간 경험, AI 팀 운영 능력
3. ⚠️ **예전 "유명 선수 훈련 영상 판매"는 권리 확인이 먼저다.** 선수·소속사·촬영자의 허락(라이선스) 없이 판매했다면 저작권·초상권(퍼블리시티권) 문제가 된다. 같은 모델을 되살리려면 **직접 만든 콘텐츠이거나 계약한 콘텐츠만** 판다. [판단 — 당시 권리 관계는 미확인]

## 3. 후보 3개 (STEP 3·4)

사고 도구: **문제 재정의**(고정 수입 → 반복되는 고객 문제) + **맘 테스트**(이미 돈을 낸 적이 있나?)

| | A. 복싱 수련자 멤버십 | B. 체력 시험 준비생 | C. 운동 영상 분석 서비스 |
|---|---|---|---|
| 고객 | 복싱 입문~중급 수련자 (나중에 복싱장) | 경찰·소방·교정·군 간부 체력 시험 응시자 | 아마추어 선수·코치 |
| 반복되는 문제 | 체육관만으로는 혼자 실력이 느는지 모름, 무엇을 연습할지 모름 | 시험 날짜까지 매일 준비해야 함 | 내 자세·스파링의 문제를 모름 |
| 유튜브 역할 | 선수 기술 분석 (예전 강점) → 무료 입구 | 시험 종목 자세 분석 | 분석 샘플 |
| 웹·앱 역할 | 90일 프로그램 + 기록 + 월간 분석 | 기준 판정 + 측정 + D-day 루틴 (체력특급 엔진) | 영상 업로드 → 분석 리포트 |
| 수익 | 월 구독, 나중에 복싱장 구독 | 시험까지 월 구독, 학원 구독 | 건당 또는 월 멤버십 |
| 이미 돈을 낸 증거 | **대표가 복싱 팬에게 판 경험** [사실, 규모 미확인] | 체력 학원·PT 지출 [사실에 가까움] | 레슨비 [사실에 가까움] |
| 실패할 이유 | 시장이 작고, 유튜브엔 무료 복싱 콘텐츠가 넘친다 | **같은 기능의 앱·측정기가 이미 있다** [확인됨, 11-21] | 대표 시간이 매번 들어감 → 확장 어려움, 복무 중 불가 |
| 지금 가능? | 무료 콘텐츠·인터뷰: 지금 / 판매: 법무관 확인 후·전역 후 | 조사: 지금 / 판매: 같음 | 전역 후 |

## 4. 판정 (STEP 5)

**추천: A. 복싱 수련자 멤버십** · 확신도 **중간-낮음**

- 이유: 세 후보 중 **"이미 돈을 낸 고객"을 대표가 직접 겪은 곳은 A뿐**이다. 그리고 대표의 고유 자산(분석 안목, 채널 경험)이 가장 많이 쓰인다.
- **반대편 변호 (가장 강한 반론):** B는 "시험 날짜"라는 강제 마감과 매년 새로 들어오는 고객이 있어서, 돈을 낼 동기가 A보다 훨씬 강하다. 복싱은 취미라 바쁘면 구독부터 끊는다.
- **뒤집힐 조건:**
  - 예전 판매가 몇 건 안 되거나 한 번 사고 끝이었다면 → A의 증거가 약해짐 → B 재검토
  - 복싱 수련자 5명 인터뷰에서 "혼자 연습할 때 무엇을 할지 모른다"는 고통이 안 나오면 → A 보류
  - 예전 판매가 권리 문제가 있는 영상 중심이었다면 → "콘텐츠 판매"가 아니라 "프로그램·기록" 중심으로 다시 설계

## 5. 다음 행동 하나 (STEP 6)

**예전 복싱 채널 판매 기록을 숫자로 적기** (대표, 10분, 개인정보 없이)
- 몇 명이 샀나 / 가격 / 다시 산 사람이 있었나 / 구독자 수 / 판매한 영상은 직접 만든 것인가, 허락받은 것인가
- 성공 기준 (결과 보기 전에 정함): **유료 구매자 20명 이상 또는 재구매자가 있었다면** A를 1순위로 조사 시작

## 7. 예전 판매 기록과 결정 (2026-11-27)

| 숫자 | 값 [사실, 대표 말] | 뜻 |
|---|---|---|
| 구독자 | 약 3,000명 | |
| 상품 · 가격 | 유명 복서 훈련 루틴 PDF (직접 만듦) · 2,000원 | |
| 산 사람 | 약 70명 | 구독자 중 약 **2.3%**가 돈을 냄 |
| 다시 산 사람 | 5명 | 산 사람 중 약 **7%**가 또 삼 |
| 매출 | 약 14만 원 (계산: 70 × 2,000원 = 140,000원, 재구매 포함 시 조금 더) | 생활비가 될 규모는 아님 |
| 판매 기간 | 미확인 | |

- **성공 기준 통과**: 구매자 20명 이상 ✅, 재구매 있음 ✅ → 5절 기준대로 A를 조사 1순위로. 대표도 A 선택.
- **확인된 것**: 복싱 팬은 **"유명 선수처럼 훈련하는 법"에 돈을 낸다** (적은 돈이라도). 재구매자 5명 = 다음 것을 기다리는 사람이 있었다.
- **아직 모르는 것**: 2,000원 한 번 사는 것과 **매달 1만 원 안팎을 내는 것**은 전혀 다른 결정이다. 구독할 만큼 "매달 다시 생기는 문제"가 있는지가 다음 검증.
- ⚠️ 유명 선수 이름을 상품명에 쓸 때: 선수가 보증한 것처럼 보이면 퍼블리시티권 문제가 될 수 있다 → "OOO 스타일 분석" + "선수와 무관한 개인 분석" 표시. 판매 재개 전 확인.

### 고정 수입 계산 (목표 감각용) [계산, 가설]
- 예: 월 9,900원 × 100명 = 월 99만 원
- 예전 비율(2.3%)이 구독에도 그대로라고 **가정하면** 구독자 약 4,300명 필요. 하지만 구독은 한 번 구매보다 전환이 낮은 게 보통이라 **실제로는 더 많은 시청자가 필요할 가능성이 크다** [추정].
- → 전역 전 무료 기간에 **구독자 늘리기 + 매달 내는 이유 찾기**가 할 일.

### 인터뷰 질문 (맘 테스트: 미래 말고 과거 행동만 묻는다, 상품 설명 금지)
1. 복싱 한 지 얼마나 됐고, 일주일에 몇 번 가요?
2. 체육관 밖에서 혼자 연습한 마지막 날, 뭘 했어요? 그건 어떻게 정했어요?
3. 실력이 늘고 있는지 어떻게 알아요? 마지막으로 "늘었다" 느낀 건 언제였어요?
4. 복싱 실력 때문에 체육관 회비 말고 돈 쓴 적 있어요? (PT, 영상, 장비, 앱) 얼마였고, 지금도 써요?
5. 복싱을 그만두고 싶었던 적 있어요? 왜요? 아니면 그만둔 친구는 왜 그만뒀어요?
6. 유명 선수 훈련법 따라 해 본 적 있어요? 해 보니 뭐가 어려웠어요?
- 끝나고 기록할 3가지: 반복해서 나온 고민 / 이미 돈 쓴 곳과 금액 / 놀라웠던 말 한 줄
