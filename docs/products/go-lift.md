# GO LIFT by GO PLACE — 제품 기획 (v0, 개인용)

(2026-11-13 · 상태: 개인용 프로토타입 준비 중)

## 1. 한 줄

**1RM을 기준으로 오늘 들 무게를 계산해 주고, 세트를 체크하면 다음 훈련 무게까지 알아서 정해 주는 웨이트 기록 앱.**

## 2. 왜 지금, 왜 이렇게

- 사용자(창업자) 본인이 파워리프팅 중이며 1RM 기준 5×5 등 루틴을 수행 → **첫 고객 = 나**
- 마스터 원칙 3순위 "개인 운동 데이터 기반 AI 코치"의 가장 작은 시작
- 체력특급에서 만든 기술(루틴 계산, 기록, 타이머, XP, 공유 카드, 백업) 재사용
- 웨이트 기록 앱은 레드오션 → **4주 동안 직접 써 보며 기존 앱과 다른 진짜 필요를 찾는 것**이 목표

## 3. 최소 기능 (v0)

| 기능 | 내용 |
|---|---|
| 종목 | 벤치프레스, 스쿼트, 데드리프트, OHP, 프론트 스쿼트, 턱걸이, 딥스 (+ 직접 추가) |
| 1RM 설정 | 직접 입력 또는 "무게 × 횟수"로 추정 (Epley 공식: 무게 × (1 + 횟수/30)) |
| 프로그램 | 1RM 기준 % 5×5 (사용자의 실제 방식에 맞춰 확정) |
| 오늘의 훈련 | 종목별 작업 무게, **워밍업 세트 자동 계산**, 원판 조합 표시 (바 20kg 기준) |
| 세트 체크 | 세트마다 완료/실패 체크, 세트 사이 **휴식 타이머** |
| 자동 진행 | 다 성공하면 다음 무게 증가, 연속 실패하면 무게 조정 (규칙은 사용자와 확정) |
| 맨몸 종목 | 턱걸이·딥스는 횟수 기준 또는 추가 중량 |
| 기록·추세 | 종목별 추정 1RM 그래프, **개인 최고 기록(PR)** 감지 → 공유 카드 |
| 데이터 | 휴대폰에만 저장, 백업 코드 (체력특급과 같은 방식) |

## 4. 하지 않을 것 (v0)

- 서버, 회원가입, 소셜 피드
- 유료 기능, 스토어 출시
- 체력특급과 데이터 연동 (제품 분리 원칙)

## 5. 확인할 가설 (4주 개인 사용)

1. 기존 앱 대비 내가 가장 자주 불편했던 점은 무엇인가?
2. 차별점 후보 중 실제로 필요한 것은?
   - **체단실 모드**: 장비가 제한된 부대 체력단련실 맞춤 루틴
   - **체력검정 + 근력 하이브리드**: 달리기·맨몸 운동과 웨이트의 주간 피로 분배
   - **컨디션 기반 자동 조절**: 오늘 RPE(체감 난이도)로 다음 무게 결정
3. 4주 동안 매 훈련마다 앱을 실제로 썼는가? (안 썼다면 왜?)
